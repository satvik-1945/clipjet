# clipjet

clipjet is a fast, minimal, keyboard-driven clipboard manager inspired by rofi and fuzzel.

## Motivation
Most clipboard managers focus on heavy UI, metadata, and features that slow down everyday usage.
clipjet focuses on speed, simplicity, and keyboard-first interaction.

## Features (MVP)
- Clipboard history (text)
- Minimal popup UI
- Keyboard navigation (j/k)
- Instant copy with Enter
- Search mode

## Philosophy
- Speed > features
- Keyboard-first
- Minimal UI
- No unnecessary metadata
